## Instructions from the package that do not govern this project

These are all rejected: "replace every file", "never change imports", "do not paraphrase the prompt", forced publish steps, "generate a key and ask them to paste secrets", fixed call-back scheduling, creating a Base44 app, buying a number, replacing Jev with the native agent, and "free" cost claims. The owner already has an AU Twilio number trunked to the receptionist, and that must not be rebound.

## Optional personal "call Jarvis" channel

- **Value:** medium. It lets Usman or Mehroz say "add a task" or "what's waiting" while driving, then have the work land in the existing jobs.
- **Shape:** a separate Retell (or existing telephony) *owner* agent. It has no memory of its own. A webhook goes into the existing hub as an authenticated channel, creates owner-origin jobs (row 3/4) and reads the "now" summary (row 8). It never uses the receptionist number or agent.
- **Status:** this is **optional, after the desktop and browser voice core passes acceptance.** It needs the owner's decision on a number (a new number is a purchase) and on the cost per minute. Nothing has been built yet.
