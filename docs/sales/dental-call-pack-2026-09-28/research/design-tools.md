### 2. Motion (motion.dev)
- **Licence**: MIT, open source, free for personal and commercial use ([npmjs.com/package/motion](https://www.npmjs.com/package/motion)).
- **Free vs Motion+**: the core library is entirely free. Motion+ ([motion.dev/plus](https://motion.dev/plus)) is a one-time-purchase add-on — 450+ premium examples, Motion UI components, and an "AI Kit" — with a perpetual, non-exclusive personal+commercial licence and lifetime updates. Per the terms page, you may not redistribute, resell, sublicense or "bundle" the Motion+ source/APIs as a standalone or competing product. There is also MotionScore, a separate paid monthly subscription for animation "auditing," unrelated to the core library.
- **Bundle size**: `useAnimate` mini is ~2.3 kB (smallest React animation primitive available); hybrid mode is ~17 kB. The full `motion` component tree-shakes no smaller than ~34 kB. Using `LazyMotion` + the `m` component gets the initial bundle down to ~4.6 kB, loading the rest sync/async as needed ([motion.dev/docs/react-lazy-motion](https://motion.dev/docs/react-lazy-motion), [motion.dev/docs/react-reduce-bundle-size](https://motion.dev/docs/react-reduce-bundle-size)).
- **Reduced motion**: ships `useReducedMotion()` and `MotionConfig reducedMotion="user"`, which auto-disables transform/layout animation for users with OS-level reduced-motion while preserving opacity/colour transitions. Returns `false` during SSR to avoid hydration mismatches.
- **React/Next 15–16 compatibility**: works with the Next.js App Router; requires `'use client'` on any file using Motion components (server components can't host it directly). Community guidance (Sep 2026) specifically covers integrating Motion into Next.js 16 without sacrificing Server Components.

### 3. Anime.js v4
- **Licence**: MIT, free, 100% open source ([github.com/juliangarnier/anime](https://github.com/juliangarnier/anime)).
- **Bundle size**: ~17 kB minified+gzipped for the full engine; v4 offers granular submodule exports so you only pay for the parts you use (timeline, SVG, scroll, text-split, etc. can be imported individually).
- **Strengths vs Motion**: a dedicated Timeline API for orchestrating multi-step sequences with synced callbacks; a built-in SVG module (`morphTo()`, `createDrawable()`, `createMotionPath()`) for shape morphing, line-draw and motion-path animation with no plugin needed; a Scroll Observer API; and built-in text-splitting utilities (chars/words/lines). Motion's strengths lie elsewhere — it's built on the Web Animations API, offers React-native layout animations (its Framer Motion heritage), `inView`/scroll utilities, and tight React ergonomics (hooks, declarative props, SSR-safe reduced-motion), but it has no first-class SVG-morph or text-split utilities and no timeline orchestration API as rich as anime.js's.

**Recommendation — one library per stack:**
- **Next.js/React sites (muv-marketing, muv-demo-dental, aldergate): use Motion.** These are React codebases; Motion's hooks/component API, SSR-safe reduced-motion handling, and LazyMotion bundle-splitting fit React idioms directly, and it's already the animation dependency KokonutUI pulls in — avoids running two animation engines in one React app.
- **Static HTML site (muv-flagship-legal): Anime.js v4 is the better fit if any JS-driven animation is added at all.** It has no React dependency, works with plain `<script>` includes, and its SVG-morph/line-draw and text-split utilities suit a conservative, editorial legal site (subtle logo draw-ins, letter-by-letter headline reveals) better than Motion's React-first API. If the legal site stays CSS-only for motion (its current "time-held" conservative direction per project memory), neither library may be needed — flag this to Usman before adding either dependency there.

### 4. KokonutUI (kokonutui.com)
Confirmed identity: [kokonutui.com](https://kokonutui.com/), GitHub org [kokonut-labs/kokonutui](https://github.com/kokonut-labs/kokonutui).
- **Licence**: MIT. Every core component is MIT-licensed and free for commercial use — described on the project itself as "yours to keep."
- **Free vs Pro**: the free catalogue (100+ components) is the full open-source set. **KokonutUI Pro** ([kokonutui.pro](https://kokonutui.pro/)) is a separate one-time purchase (reported ~US$99–159 depending on promo) unlocking 100+ additional Pro components and templates, with future releases included.
- **Dependency stack**: React + Tailwind CSS + shadcn/ui patterns + Motion (for the animated components specifically). Copy-paste model — each component is standalone once copied into your project, but if you use the Motion-animated ones you inherit Motion as a real dependency, not just a dev-time one.
- **Copying rules**: MIT licence permits copying components directly into a proprietary/commercial codebase with no attribution requirement beyond standard MIT licence retention. No explicit anti-redistribution clause was found (unlike Motion+). Pro components' redistribution terms were not separately verified — treat Pro purchases as single-seat/team use only until confirmed on `kokonutui.pro/docs` (pricing page returned 404 on this pass; use the pro site's own terms before purchasing).

### 6. Manus (manus.im)
- **What it is now**: a general-purpose AI agent that can generate and host deliverables — websites, images, video, slides, docs — from a prompt, with an API for programmatic website generation ([open.manus.ai/docs/v2/website](https://open.manus.ai/docs/v2/website)).
- **Pricing/credits**: Free plan = 300 daily refresh credits (no rollover). Pro = US$20/mo for 4,000 credits or US$40/mo for 8,000 credits. Extended tier from US$200/mo. Team from US$20/seat/mo, ~17% off annually. Credit consumption per task is unpredictable — some reviewers report a single complex task consuming 900+ credits.
- **Privacy/publishing**: the Manus API lets you set `"visibility": "private"` when publishing a generated website, restricting access to the owner and invited collaborators — outputs do **not** have to auto-publish publicly.
- **Output ownership**: per Manus's own help centre, "You own all content you create with Manus — including websites, images, videos, slides, and any other AI-generated Output," free to use for personal or commercial purposes "subject to applicable laws and third-party rights." Manus retains a right to use your content operationally and in aggregated/de-identified form to improve the product, which does not affect your ownership.

### 7. Higgsfield (higgsfield.ai)
- **What it does**: AI image/video generation platform, already integrated into our Design tooling via both a direct USD API and an account-connector OAuth flow (confirmed from local doc `docs/HIGGSFIELD-API.md` in AgenticOS-v4, read-only, no `.env` opened).
- **Pricing tiers/credits** (2026, per third-party pricing trackers — Higgsfield doesn't publish a single canonical pricing page in a scrapable static form): Basic US$9/mo (120 credits), Pro US$23/mo annual or US$29/mo monthly (600–900 credits), Max US$59/mo annual or US$79/mo monthly (1,800–5,400 credits), Team US$65/seat/mo, Scale US$150/seat/mo, Enterprise custom-quoted.
- **Commercial-use rights per tier — quoted terms**: Higgsfield's Terms of Use §4.4, as summarised on their own help centre page, states Higgsfield "does not claim ownership of any of your Inputs or Outputs, nor does it restrict your commercial use of Outputs," and that "the Terms of Use do not tie commercial use rights to a specific plan." **However**, the separate pricing/marketing page lists "Commercial use: Not included" on the Free plan, and free-tier generations carry a visible watermark (paid plans remove it). This is a direct conflict between the legal terms and the marketing page — treat commercial use of **free-tier** output as unresolved/paid-only until Higgsfield support confirms in writing which document governs, especially before using free-tier Higgsfield assets in any client-facing deliverable.
- **Ownership of outputs**: users own their outputs; rights survive subscription cancellation or account deletion, and may be transferred/sublicensed to clients — relevant for client delivery work.
- **Restrictions (likeness/real people/trademarks)**: users are responsible for ensuring content doesn't infringe third-party copyright, trademark, or likeness rights; may not use another person's image without their permission; submitting rights documentation does not guarantee content is approved or exempt from moderation.
- **Free-tier commercial use**: per the above conflict, **do not treat free-tier Higgsfield output as commercially clear** for client work until confirmed with Higgsfield support.

### 8. Gemini API video understanding
- **Model names accepting YouTube URLs via `fileData.fileUri`**: the current docs example uses `gemini-3.8-flash` and do not explicitly restrict the YouTube-URL feature to a specific model list; it's described as a general Gemini API capability available "in preview, at no charge." For older models: pre-Gemini-2.5 models accept only 1 video per request; Gemini 2.5 and later accept up to 10 videos per request.
- **Free-tier limits**: capped at 8 hours of YouTube video processed per day; File API free tier max file size is 2 GB (20 GB on paid); inline video data is capped under 100 MB total request size. **Specific RPM/RPD limits per model were not found published on the static docs pages** — Google routes exact numbers to the AI Studio rate-limit dashboard (`aistudio.google.com/rate-limit`), which requires a signed-in account to view; not checked, as that's outside read-only, no-login research scope.
- **Paid price per 1M tokens for video** (video shares the standard input-token rate — no separate video-specific price line was found): Gemini 2.5 Flash — $0.30/1M input tokens (text/image/video). Gemini 2.5 Pro — $1.25/1M (prompts ≤200k tokens) or $2.50/1M (prompts >200k tokens). Gemini 3.x Flash models — $0.75/1M input tokens through 31 Dec 2026, rising to $1.50/1M from 1 Jan 2027.
