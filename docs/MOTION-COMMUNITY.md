# Motion Library

Install the workspace as described in [Community start](COMMUNITY-START.md), then open [Motion Library](http://localhost:8081/motion). The library has 103 styles and a single composer. Choose a style, describe the idea and add only assets you are entitled to use.

## Use Opus 5.5

Install and sign in to local Claude Code version 2.1.280 or newer, with access to Opus 5.5. A Claude website login alone does not install the CLI. The exact model ID is `claude-opus-5-5`; check availability in your own account. See Anthropic's [model configuration](https://code.claude.com/docs/en/model-config) and [CLI reference](https://code.claude.com/docs/en/cli-reference).

Choosing **Claude · Opus 5.5** shows the local command and project folder before launch. On macOS, the final launch button opens Terminal with the model selected. On other platforms, copy the displayed command into your terminal. Normal runtime permissions remain active.

Choosing **Codex / Astra** opens Astra as coordinator. Its handoff explicitly requires all graphics work to run through local Claude Code with Opus 5.5, and tells it to stop if that CLI or model is unavailable. Both `PROMPT.md` and `GRAPHICS.md` are saved in the generated project folder. Read the actual runtime result to confirm completion.

The ChatGPT option provides the same CLI requirement as a copied browser handoff. A browser conversation cannot itself enforce a CLI model or prove execution. It must have a working local handoff environment, or give you the prepared file and command.

Auto-enhance uses the pinned local model and reports missing access or a model mismatch. Turn Auto-enhance off to compose a plain prompt without a model call. Explicit developer template mode is labelled as a template.

## Included graphics

The release includes 103 style renderers and 12 code examples. The page has no hero lightning, and the RISE information button and popup have been removed. The 12 inspiration entries are external links. Reference-led film previews, old beam clips and personal production materials are excluded. Brand logos identify their respective products; the workspace licence does not grant ownership of those trademarks or permission to reuse someone else's reference work.

Your newly uploaded files and generated projects remain yours to review. Sharing this download does not clear future assets that you add to it. Use the original ZIP when distributing an authorised clean copy.
