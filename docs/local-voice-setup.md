# Voice setup

The current voice interface is Jarvis. Use [VOICE-RELEASE.md](VOICE-RELEASE.md) for configuration, storage and verified behavior, and [ASSISTANT-SETUP.md](ASSISTANT-SETUP.md) for model setup.

OpenAI Realtime and ElevenLabs are hosted services and can incur provider charges. A local Hermes or Codex executable may also call a cloud text model. Selecting a local text model does not by itself supply local speech recognition or synthesis.

The separate `voice-lab` prototype remains in the repository for development. Its experimental local-compatible-server path requires a separately installed speech server; it is not the supported one-command Jarvis setup, and no free, completely local voice installation is bundled.
